Install

From download to screen saver in a minute

Step 01

Download the installer

Open the DMG and launch the installer package inside.

Step 02

Let macOS install it

The package installs for all users, so System Settings will ask for your password.

Step 03

Turn on the widgets you want

Open System Settings → Screen Saver → PickleballScreensaver → Options… to choose format, theme, and widgets.
